# daily/

Registros diários do JARVIS, um arquivo por dia com conteúdo relevante.

## Formato

```
YYYY-MM-DD.md
```

Exemplo: `2026-08-09.md`

## Regras

- Não criar registros diários vazios automaticamente — um arquivo só deve existir se houver algo real para registrar naquele dia.
- O conteúdo de cada registro é livre (decisões tomadas, eventos, tarefas concluídas), mas deve ser relevante o suficiente para valer a pena persistir.
- Informação estável de longo prazo pertence a `memory/` ou `projects/`, não a `daily/` — os registros diários são histórico, não memória ativa.
