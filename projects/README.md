# projects/

Contexto persistente sobre projetos acompanhados pelo JARVIS (projetos do usuário — não o próprio JARVIS).

## Como usar

- Cada projeto acompanhado deve ter seu próprio arquivo Markdown (ex.: `nome-do-projeto.md`) ou, se crescer o suficiente, seu próprio subdiretório.
- Antes de trabalhar em um projeto já existente, consultar o contexto salvo aqui primeiro.
- Registrar apenas informação estável e útil: objetivo do projeto, decisões importantes, estado atual — não histórico detalhado de cada sessão (isso é papel de `daily/`).
